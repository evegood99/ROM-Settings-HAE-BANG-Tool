케이스를 열고, 꽂고, 플레이.

새 게임을 사 오던 날, 비닐을 뜯고 케이스를 열어 설명서를 넘기고 팩을 꽂던 그 손맛. HB런처는 그 아날로그 감성을 최대한 느낄 수 있도록 — 진열장에서 케이스를 꺼내 앞뒤를 살피고, 열어서 매체를 꺼내 본체에 꽂으면 게임이 시작되는 에뮬레이터 런처입니다.

패키지를 품에 안던 그 설렘, 그대로

파일 이름이 늘어선 목록 대신, 손에 잡히는 게임 패키지. 롬 파일을 다시 '내 물건'처럼 느끼게 하는 것이 HB런처의 전부입니다.

1

진열장에서 고르고

기종마다 쌓인 케이스 더미에서 오늘 할 게임을 꺼냅니다.

2

앞뒤로 살펴보고

앞표지·책등·뒷표지를 돌려 보며 한국어 제목과 발매연도를 확인합니다.

3

케이스를 열면

클램셸·종이곽·쥬얼케이스 — 실물처럼 열리고 설명서와 매체가 나옵니다.

4

꽂으면 시작

카트리지·디스크·UMD·게임카드를 본체에 꽂으면 브라운관이 켜지며 게임이 시작됩니다.

케이스와 매체는 기종마다 실물 치수(mm) 그대로 — 손에 쥐던 크기와 무게감까지 화면 위에 되살렸습니다.

HB런처 화면

받아서 켜면 이렇게 나옵니다. 왼쪽은 Windows판, 오른쪽은 안드로이드판(RG 476H 실기기) — 같은 순서로 따라가 보세요.

메가드라이브 진열대 → 소닉 2 앞·뒤표지 → 케이스를 열어 브라운관에 플레이 영상 → 슈퍼패미컴 종이곽 · PS1 쥬얼케이스 → 옵션 › 화면 › 시스템 표시 › 기기(진열대에 본체가 섭니다) → 시스템 탐색 방식 › 브랜드별 탐색(SONY · SEGA · NINTENDO)

해방툴 필수

진열장은 해방툴이 채웁니다

HB런처는 해방툴과 함께 씁니다. 표지·책등·뒷표지·설명서·영상이 담긴 라이브러리는 해방툴이 만들어 보내 줍니다.

  1. 1해방툴에서 롬을 추가하면 게임 정보와 미디어가 자동으로 맞춰집니다.
  2. 2[HB런처]로 내보내기 — 안드로이드 기기는 USB·무선으로, Windows는 내 컴퓨터로 바로 보냅니다.
  3. 3HB런처를 켜면 기종별 진열장이 완성되어 있습니다.
무선 내보내기

선 없이, IP 입력 없이 — 무선으로 보내기

게임기에서 SELECT 한 번, 해방툴에서 [자동 찾기] 한 번. 같은 Wi-Fi의 게임기를 찾아 IP까지 자동으로 연결하고 그대로 보냅니다.

▶ 실제 화면 — 해방툴 + RG 476H SELECT로 무선 받기 → [자동 찾기]로 연결 → 내보내기 → 진열장에 새 게임. 58초
