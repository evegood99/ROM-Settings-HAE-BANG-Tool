개발 미리보기

지금 이만큼 만들어졌습니다

아래 영상과 이미지는 목업이 아니라 개발 중인 빌드를 그대로 녹화한 실제 화면입니다.

▶ 실제 동작 영상 기종 진열대를 훑고 → 케이스를 열어 앞뒤로 살펴보고 → 내장 화면으로 플레이 영상을 보다가 그 자리에서 게임 시작 → 카트리지·UMD를 실물 본체에 꽂아 실행까지. 베타 0.5 빌드를 그대로 녹화한 1분 8초
유튜브에서 보기 — 이게 게임 런처라고?팩 넣는 감성까지 담은 해방런처 · 해방 레트로 채널
▶ 실기기 구동 — RG 476H안드로이드 핸드헬드에서 그대로 — 진열대, 케이스 개봉, 본체에 꽂아 실행, 기종별 에뮬레이터 옵션까지. 베타 0.5 빌드, 2분 11초
▶ 해방툴 → HB런처 전송해방툴의 [HB런처] 내보내기가 롬·미디어를 기기로 밀어 넣는다 — 기기 화면에 진행이 그대로 뜨고, 끝나면 새 시스템이 진열대에 선다
① 기종 진열대쌓아 둔 케이스 더미와 기종 로고 — 해방툴이 다루는 50개 기종 전부
② 게임 고르기한국어 제목·발매연도·제작사를 해방툴 DB에서 함께 가져온다
③ 클램셸 — 메가드라이브책처럼 열리면 뚜껑에 설명서, 뒷판에 카트리지 — 그 자리에서 게임 정보·영상 보기·게임 시작
④ 종이곽 — 슈퍼패미컴곽을 눕혀 열고 설명서와 팩을 옆으로 꺼내 늘어놓는다
⑤ 쥬얼케이스 — PS1투명 케이스가 열리며 책자와 디스크가 드러난다
⑥ 꽂으면 실행 — 실물 본체꺼낸 카트리지·디스크가 그 기종의 본체에 꽂히며 게임이 시작된다

* 베타 0.5 빌드의 실제 화면입니다. 기종마다 실물 케이스 구조와 매체(카트리지·디스크·UMD·게임카드)를 실제 치수(mm)대로 만듭니다. Windows에서 RetroArch 실행, 안드로이드 핸드헬드 실기기(60fps) 구동까지 검증되었습니다.

베타 0.5

이번 빌드에서 달라진 것

  • 여러 게임기의 모델·텍스처와 본체 표시 크기를 다듬었습니다.
  • NES 카트리지·PSP UMD 를 입체로 만들고, 삽입·배출 동작을 보정했습니다.
  • 내장 화면 영상 재생, 게임 시작·종료 때의 확대와 잡음 연출을 개선했습니다.
  • A/B 버튼 안내, 영상에서 바로 게임 시작, 빠른 뒤로 가기 오류 수정.
  • 에뮬레이터 목록을 해방툴 기준으로 갱신했습니다.
계획된 특징

보기만 예쁜 런처가 아닙니다

🕹️

RetroArch 기본 + 확장 연결

RetroArch를 기본 호환으로 하고, 시스템별 스탠드얼론 에뮬레이터는 연결 정보를 통해 추가합니다. 새 에뮬레이터 대응은 앱 업데이트 없이 데이터 갱신만으로 이뤄지도록 설계하고 있습니다.

🔗

해방툴과 다이렉트 연결

안드로이드 기기에 HB런처가 있으면 해방툴이 롬과 미디어를 기기로 바로 밀어 넣습니다. 해방툴에서 세팅한 라이브러리는 매칭 과정 없이 즉시 진열장이 됩니다.

🧠

해방툴이 다루는 50개 기종 전부

패미컴·메가드라이브부터 PC엔진·새턴·PS1, GBA·원더스완·네오지오 포켓, DOS·아미가 빅박스까지. 기종마다 케이스 형태와 매체가 다르고, 같은 기종 안에서도 판본에 따라 상자가 달라지는 것까지 반영합니다.

🎯

게임패드 우선 · 핸드헬드 우선

모든 조작을 패드 버튼만으로. 안드로이드 게임 핸드헬드의 저사양 GPU에서도 부드럽게 돌도록 처음부터 가볍게 만들고 있습니다.

다운로드

HB런처 받기

PC에서는 Windows판을, 안드로이드 게임기에서는 APK를 받으세요.

Windows

준비 중

Windows용 압축 파일(zip)로 받습니다. 압축을 풀고 바로 실행하세요.

Android (APK)

준비 중

구매 시 발급되는 APK 코드를 입력하면 받을 수 있습니다. 안드로이드 게임기에 설치하고, 해방툴의 [HB런처] 내보내기로 라이브러리를 채우세요.

배포가 시작되면 새로운 소식 페이지에서 알려 드립니다.

개발 소식을 지켜봐 주세요

HB런처는 지금 한창 만들어지는 중입니다. 진행 소식은 새로운 소식 페이지에 계속 올라오고, 그동안 해방툴로 라이브러리를 먼저 세팅해 두시면 런처가 나왔을 때 바로 이어집니다.
