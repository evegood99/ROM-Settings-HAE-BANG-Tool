컨테이너는 알아서, 윈도우 게임은 누르면 바로

안드로이드에서 윈도우 게임을 돌리는 Winlator 에, 해방툴이 첫 준비(시스템 파일 · 런타임 · 컨테이너)까지 대신 하는 준비 브릿지를 더했습니다. 기기에서 앱을 열어 설정하지 않아도, PC 에서 보낸 게임을 ES-DE · Pegasus · HB런처에서 눌러 바로 켭니다. 다른 Winlator 옆에 나란히 설치됩니다.

HB윈레이터 받기 (GitHub) 무엇이 쉬워지나요? ↓
최신 5.0-hb2 무료 · 오픈소스(GPLv3) Winlator Ludashi 5.0 기반 안드로이드 9+ · 64비트 해방툴 · HB런처 연동

해방툴 연동(자동 준비 · 윈도우 게임 내보내기)은 해방툴 v1.2 부터 동작합니다 — v1.2 는 곧 공개됩니다. 그 전에도 HB윈레이터는 지금 받아 일반 Winlator 처럼 쓸 수 있습니다.

더한 것 · 고친 것

게임기에서 손이 덜 가는 Winlator

Winlator Ludashi 5.0 을 바탕으로, 처음 준비를 바깥에서 시킬 수 있게 하고 게임기 화면에서 걸리던 문제를 고쳤습니다. 게임 실행 · 설정 · 그래픽 드라이버는 원래 Winlator 와 같습니다.

hb1
🔌

준비 브릿지

Winlator 는 앱을 처음 열었을 때의 화면에서만 스스로를 준비하고, 컨테이너는 앱 안쪽에 있어 바깥에서 만들 수 없었습니다. HB윈레이터는 준비됐는지 알려 주고, 화면 없이 시스템 파일 · 런타임 · 첫 컨테이너까지 준비합니다.

설치한 뒤 한 번도 열지 않고 준비: RG 476H 29초 · AYN 오딘 2 13초

hb2
🖥️

화면 맞춤

컨테이너 화면보다 작은 해상도로 전체 화면을 잡는 게임은 화면 왼쪽 위 구석에만 그려지고 나머지가 검게 남았습니다. 이제 그 영역을 기기 화면에 맞춰 키우고(비율 유지), 터치 · 마우스 위치도 따라갑니다.

창 모드 프로그램 · 메뉴가 밖에 뜬 화면은 키우지 않습니다. Vulkan · EGL · DisplayX 모두

hb2
🌐

기기 언어

바깥에서 만든 컨테이너는 언어 값이 없어 Wine 이 영어로 동작했고, 처음 켤 때 시스템 언어로 게임 언어를 정하는 게임이 계속 영어로 남았습니다. 이제 컨테이너가 기기 언어(한국어 기기면 한국어)로 돕니다.

이미 영어로 저장된 게임은 게임 안 설정에서 한 번 바꿔 주세요

hb2
🩹

첫 실행 검은 화면

창 모드로 떴다가 전체 화면으로 바뀌는 게임(Unity 게임에 흔합니다)이 처음 켤 때 소리만 나고 화면이 검던 문제를 고쳤습니다. 화면 밖에 숨겨 둔 옛 게임 창이 통째로 그려져 진짜 화면을 덮고 있었습니다.

RG 476H 에서 첫 실행 조건을 되살려 확인 — 평소처럼 약 80초에 타이틀

hb1
📦

나란히 설치 · 드라이버는 저절로

앱 이름(패키지)이 달라 쓰던 Winlator 를 지우지 않아도 됩니다. 그래픽 드라이버는 기기의 그래픽 칩에 맞게 저절로 정해지고, 새 버전을 덮어 설치해도 컨테이너와 세이브는 그대로 남습니다.

Mali-G57(RG 476H) · Adreno 740(AYN 오딘 2)에서 확인

바깥에서 할 수 있는 일은 정해져 있습니다

자주 묻는 것

알아 두면 좋은 것

모든 윈도우 게임이 되나요?

아니요. 게임마다의 호환성과 성능은 Winlator(Wine · Box64 · 그래픽 드라이버)와 기기의 그래픽 칩에 달려 있습니다. HB윈레이터는 준비와 화면 문제를 고친 것이고, 호환성을 바꾸지는 않습니다. 런타임(VC++ · .NET) 설치가 필요한 게임은 Winlator 에서 직접 해야 합니다.

다른 Winlator 는 지워야 하나요?

아니요. 앱 이름(패키지)이 달라 나란히 깔립니다. 컨테이너는 앱마다 따로라, 다른 Winlator 에서 만든 컨테이너는 보이지 않습니다.

원래 Winlator 와 뭐가 다른가요?

Winlator Ludashi 5.0 을 바탕으로 준비 브릿지를 더하고, 화면 맞춤 · 기기 언어 · 첫 실행 검은 화면을 고쳤습니다. 게임 실행 방식과 설정은 같습니다. Winlator 개발자들과 관계없는 비공식 빌드이고, 소스는 GPLv3 로 공개합니다.

어떤 기기에서 되나요?

안드로이드 9 이상의 64비트(arm64) 기기입니다. Anbernic RG 476H(Mali-G57)와 AYN 오딘 2(Adreno 740)에서 확인했습니다. 그래픽 드라이버는 기기에 맞게 저절로 정해집니다.

해방툴 없이도 쓸 수 있나요?

네. 앱을 한 번 열어 안내대로 진행하면 원래 Winlator 처럼 쓸 수 있습니다. 화면 맞춤 · 기기 언어 · 첫 실행 고침은 그대로 적용됩니다.

게임 폴더는 어디에 들어가나요?

내부 저장소의 Download/WinGames 아래입니다(컨테이너의 D: 드라이브). 용량이 큰 게임은 내부 저장소 여유를 확인하세요. SD 카드에 둔 게임 폴더는 컨테이너 설정에서 드라이브로 직접 이어야 합니다.

게임이 화면 한쪽 구석에만 나와요

5.0-hb2 부터 작은 전체 화면 게임은 저절로 화면에 맞춰집니다. 창 모드로 뜨는 게임은 키우지 않으니, 게임 설정에서 전체 화면으로 바꿔 보세요.

게임이 영어로 나와요

예전에 영어로 시작해 그 설정을 저장한 게임입니다. 게임 안 설정에서 언어를 한 번 바꿔 주세요. 새로 넣은 게임은 기기 언어로 시작합니다(게임이 그 언어를 지원할 때).

게임을 끝냈는데 프론트엔드로 안 돌아가요

게임을 끝내도 Winlator 화면은 남습니다. 뒤로 가기로 메뉴를 열어 직접 닫아 주세요. 다음 업데이트에서 살펴보고 있습니다.

새 버전은 어떻게 설치하나요?

GitHub 릴리스에서 새 APK 를 받아 쓰던 HB윈레이터 위에 그대로 설치하면 됩니다. 컨테이너와 그 안의 세이브 · 설정은 그대로 남습니다. 앱을 지우면 컨테이너도 사라지니 지우지 말고 덮어 설치하세요.

언제부터 해방툴과 이어지나요?

해방툴 v1.2 부터입니다(곧 공개). v1.2 에는 PC 윈도우 시스템과 안드로이드 기기로 보내기가 함께 들어갑니다. HB윈레이터는 지금 받아 설치해 두어도 됩니다.

GitHub 저장소의 Issues 나 홈 화면 맨 아래 문의 칸으로 알려 주세요. 원래 Winlator 저장소가 아니라 이쪽에 남겨 주세요.
